# 부캉이와 함께하는 첫 QC 업무

신입 QC 매니저가 파란 상어 **부캉이**와 함께 직접 클릭·키보드·마우스로 첫 업무를 완료하는 React + Vite 실습 목업입니다. 실제 API·DB·로그인·API 키·`.env` 없이 실행합니다. 모든 기관·지원자·파일은 가상 데이터입니다.

## 실행

개발·검증 버전은 **Node.js 24**입니다. Vite 지원 버전인 Node.js 20.19+ 또는 22.12+도 사용할 수 있습니다.

```sh
npm ci
npm run dev
```

기본 개발 포트는 5173입니다. 프로덕션 빌드는 `npm run build`, 빌드 확인은 `npm run preview`입니다.

```sh
npm test             # 모델·검출/취소 규칙·이력 테스트 7개
npm run test:e2e     # Chromium 실제 조작 시나리오 7개
npm run build        # 프로덕션 dist/ 생성
npm run format:check # 코드 형식 확인
```

브라우저 테스트는 `/usr/bin/chromium`을 우선 사용합니다. 다른 시스템 브라우저는 `CHROMIUM_PATH`로 지정하세요. 시스템 브라우저가 없으면 `npx playwright install --with-deps chromium`으로 공식 브라우저와 Linux 의존성을 설치할 수 있습니다. E2E 러너가 개발 서버를 시작하며, 이미 실행 중인 서버는 재사용합니다(`CI`에서는 새 서버 사용). 캡처와 실패 기록은 무시되는 `test-results/`에 생성합니다.

## 다섯 여정 · 열세 미션

1. **나의 첫 워크스페이스** — 왼쪽 메뉴 → 한빛공사 → 파일 A의 QC하기. 첫 출근 완료 배지.
2. **검출 도구 익히기** — E + 한빛대학교 전체 드래그 → 출신지역 토글 + 서울 드래그 → D + 한빛대학교 전체 드래그. 검출 도구 입문자 배지.
3. **원본 파일의 비밀** — 파일 A에서 김하늘 검출 → 파일 B에서 취소 제한 경험 → 파일 A에서 취소. 원본 파일 수호자 배지.
4. **연결된 QC스페이스** — 김하늘 재검출 → QC스페이스 → 파일 A 과업 상세 → 김하늘 취소. QC 연결 탐험가 배지.
5. **첫 업무 완료** — 워크스페이스 → 기관 → 파일 A → 동기화 확인 → 1·2·3번 문항 확인 → 검토 완료 → 파일 목록의 QC 완료. QC Rookie 배지.

처음에는 흐려진 실제 업무 화면 위에 부캉이의 인사가 표시됩니다. 시작 버튼은 실습 진입만 처리합니다. 챕터 소개의 **실습 시작**도 미션 성공으로 처리하지 않습니다. 한 미션 안의 파일 전환·카테고리 선택·과업 진입·문항 확인 안내는 조작 직후 자동으로 바뀝니다. 미션 전체가 성공해야 **다음 미션** 버튼이 열립니다.

## 안내와 업무 화면

- 자체 제작 SVG 부캉이: 작은 지느러미·사원증, 인사·위치 안내·응원·축하 표정과 동작.
- 큰 말풍선: 현재 여정·미션, 행동 한 가지, 필요한 키와 드래그 대상, 즉각적인 성공·실패 피드백.
- SVG 마스크 스포트라이트와 손 포인터: 실제 DOM 위치를 `ResizeObserver`, 스크롤·리사이즈 이벤트로 추적합니다. 오버레이는 `pointer-events: none`으로 버튼·본문 선택을 가로채지 않습니다.
- 인사·소개·완료는 배경 흐림과 조작 차단을 적용합니다. 대화상자의 키보드 초점 순환을 지원합니다.
- 관련 없는 메뉴·버튼은 현재 대상을 재안내합니다. 잘못 검출한 내역을 D로 취소하거나 카테고리를 고치는 복구 도구와 심화 실습의 의도된 취소 제한은 허용합니다.
- 회사 업무 화면의 좌측 메뉴, 기관 요약·검색·목록 표, 원본 파일/OP 결과 파일, 상태 태그, 지원자·문항·본문·검출 내역 구획을 유지합니다.
- 여정 노드의 잠김/진행 중/배지 획득, 진행률, 챕터별 보상, 완주와 네 가지 재연습 버튼을 제공합니다.
- `prefers-reduced-motion` 지원, 초점 표시, 좁은 화면 대응. E/D 실습은 물리 키보드·마우스를 권장합니다.

## 데이터·미션 규칙과 복원

실제 DOM 선택 범위의 UTF-16 시작·끝 위치(끝 제외)를 검사합니다. 키는 드래그 시작 전부터 끝날 때까지 유지해야 하며, 도중에 놓았다 다시 눌러도 해당 드래그는 거부합니다. E 키만 누르거나 부분 범위를 선택해 미션을 완료할 수 없습니다.

검출은 ID·텍스트·범위·카테고리·원본 파일·활성/취소 상태·이벤트 이력을 보존합니다. 중복·겹침을 거부하고 D 취소는 정확한 전체 범위의 단일 내역만 처리합니다. 파일 B에서 파일 A의 검출을 취소하면 차단 사유와 함께 원래 검출을 유지합니다. 이 차단 결과 자체가 미션 8의 성공 조건입니다.

워크스페이스와 QC스페이스는 App의 하나의 검출 상태를 사용합니다. 검출이 있는 파일에는 과업이 생성되고 취소 후에도 과업과 이력은 남습니다. 성공 결과를 되돌리면 미션 조건을 다시 검사해 다음 미션을 잠급니다. 오류로 진행률·배지를 차감하지 않습니다.

진행·검출·배지·챕터 소개·문항 확인·이전 미션 스냅샷은 브라우저 localStorage(`qc-academy-v1`)에 저장합니다. 대사와 강조 대상은 저장된 화면·파일·카테고리·문항 상태에서 계산하므로 새로고침 후 이어집니다. 누르고 있던 물리 키 상태는 안전하게 초기화합니다. 전체/기능별 재시작 전 초기화 범위를 안내하며 기능별 시작에는 필요한 예시 데이터를 준비합니다. 이전 미션으로 돌아가면 그 미션의 스냅샷을 복원합니다.

## 검증 범위

브라우저 시나리오는 13개 미션 완주, 실제 클릭·텍스트 드래그, 키 입력만으로 미완료, 부분 범위·카테고리 오류 복구, 성공 후 취소 시 다음 미션 재잠금, 다른 파일 취소 제한과 ID 보존, 원본 파일/과업 취소, 동기화와 QC 완료를 검사합니다. 추가로 프롤로그 배경 차단, 잘못된 메뉴 재안내, E 입력·카테고리·파일·과업 진입 직후 대사/대상 전환, 중간 키 해제, 챕터 소개·배지·문항 복원, 1440/1200/1000/390px 위치 추적, 모션 감소, 390px 가로 넘침을 검사합니다.

## 참고자료와 확인 필요 항목

제공된 **백오피스 QC 업무 가이드 1~7페이지**와 워크스페이스·상세·QC 화면 캡처를 참고했습니다. 문서와 이미지는 참고자료로만 사용했으며 저장소에 복제하지 않습니다. 실제 지원자 정보도 포함하지 않습니다.

- 기관 목록의 큰 열 구성과 파란 표 헤더, 상세의 원본/OP 파일 구분, QC의 지원자·본문·검출 구획을 반영했습니다. 실습 규모에 맞춰 기관 1곳·파일 2개·지원자 1명·문항 3개로 축소했으며 화면을 픽셀 단위로 복제한 구현은 아닙니다.
- 제공 자료에 없는 **QC스페이스의 정확한 회사 화면**, 검출 카테고리 상세 디자인, 부캉이 브랜드 최종 도안은 확인이 필요합니다. 해당 부분은 요청서의 동작과 자체 디자인으로 구현했습니다.
- PDF의 자동 완료/저장 흐름은 요청서에 따라 명시적인 **검토 완료**와 목록 복귀로 단순화했습니다. 세 문항은 실습용 공통 본문을 사용하고 질문 제목과 확인 상태를 전환합니다.
- 실제 API·DB·로그인·원본 파일 편집/다운로드·운영 검색 필터·다수 지원자 처리는 구현 범위 밖입니다. 원본 파일 표는 현황 표시용이며, 실습 메뉴·기관·QC·카테고리·본문·문항은 실제 조작 가능합니다.
- PDF 8페이지 이후 취합·딥셀렉은 제외했습니다. 별도의 게임 참고 이미지는 제공되지 않아 요청서의 어두운 배경·캐릭터·말풍선·집중 대상 표현을 자체 구현했습니다.
- 저장은 현재 브라우저에만 유지되며 다른 기기와 공유되지 않습니다.
